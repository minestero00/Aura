# 교통수단 알림

## 의도

유저가 처음에 목적지를 검색하는 시점부터, 어느 목적지를 갈 때, 그 부분에서 user에게 언제 내리고, 갈아타고 하는 시점을 미리 액션을 알려주기 위함

## input

현 위치에서 출발한다고 가정하고 할 것이다. 다른 장소에서 출발 하는 시점에서 탑승에 대한 알림을 받는 의미는 없다

1. 목적지(google map)

   해당하는 경로를 google map을 기반으로 보여줌. 선택지를 제공(자연스러운 검색창 밑에 예상 결과 표시)

   ex.

   - 버스1 -> 지하철 1
   - 버스1

   등 이런 방식으로 가는 길이 있을 것임. 그 중 버튼으로 선택

## Output

gps 정보 계속 받다가, 버스 or 지하철 기준 gps 좌표 어느 정도 기준에 왔으면 알림.

- 이 알림은 앱이 background에 있을 때 돌아갈 수 있게 해야한다. push alarm 형식으로 해야한다.

## example

실제 목적지 : 광운대학교

현재 위치 : 옥수역

---

### input

목적지 : 광운대학교

현 위치 : 옥수역

- 이 값은, gps 값을 통해서 받을 것이다.

### output

지하철 경로 선택.

갈아타는 시점에서도 계산. 갈아타는 역 거리 어느 정도 전에 push alarm 발송.

최종 목적지 걸어가는 거리 빼고, 교통수단을 갈아타거나 아예 내리는 시점 모두에 대해서 표시해야한다.
