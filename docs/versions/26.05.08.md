# 2026-05-08 패치 노트

Alpha → Beta 전환을 향한 큰 패스. Railway 정식 배포가 가장 큰 이벤트.

## Features

1. 유저가 원하는 뉴스 토픽(최대 5가지)에 대한 요약을 받아볼 수 있음. 실제 뉴스 링크도 제공함.

   - briefing by anthropic api
   - 일일 브리핑 스냅샷 30분 캐시 + 워커 사전 계산 (재요청 비용 절감)

2. 유저의 로그인한 구글 계정 기반으로 하루치 메일 분석 및 답변 초안 작성해줌

3. 유저의 휴대폰에 저장된 캘린더 + 구글 캘린더 내용을 가져와서 오늘, 내일 할 일 알려줌.

   - 다음 일정을 맞추기 위해 대중교통/자차로 언제 출발해야하는지 값 제공. + Google Maps 연동

4. Aura Chat. 일일 브리핑(메일/뉴스) context를 그라운딩한 답변 + 스트리밍.

   - 처음엔 "쓸모 모르겠다" 였는데 일일 브리핑을 자연어로 묻는 용도로 굳어지는 중.

## 인프라 / 운영

- **Railway에 backend 정식 배포** — 같은 프로젝트 `aura-backend` 안에 `aura-api` + `aura-worker` + `Redis` 3개 서비스. internal 호스트(`redis.railway.internal`)로만 통신, public 노출 X.
- **마이그레이션 가드 fail-soft 화** — `aura.briefings`는 있는데 `aura.schema_migrations` 추적 테이블이 없을 때 throw 대신 모든 알려진 `.sql`을 applied로 마킹. 외부 시드된 schema(Supabase Dashboard 직접 적용 등)에서도 첫 부팅이 자동 회복.
- **`aura` schema 단독 소유 정책 명시** — `back/CLAUDE.md` DB 연결 규칙에 명시. dumb이 관리한다는 옛 주석(`0006_user_profiles.sql`) 정정.
- **`GOOGLE_MAPS_API_KEY`를 preflight 강제 검증에서 제외** — transit 모듈에서만 쓰고 미설정 시 503 graceful 처리이므로 부팅 가드 불필요.

## Sign-in 안정화

- **Supabase JS의 `processLock` 제거** — Node 서버용 file/process lock인데 RN AsyncStorage에 stuck lock state가 남으면 다음 모든 auth 호출(`signInWithIdToken`, `getSession`)이 영원히 wait. sign-in spinner가 끝나지 않는 hang의 직접 원인이었음. RN은 단일 process라 default(no-op) lock으로 충분.

## 디자인

### 1차 패스 — 화면 진입 모션

- **`auraMotion` 토큰 신설** — `front/src/features/app/styles/theme.tsx`. duration / easing / screen-enter spec(거리·stagger).

- **화면 진입 모션 패턴 정식화** — `aura-app-design-system/references/patterns.md`에 "화면 진입 모션" 섹션. 위 카드(translateY -120 → 0) + 아래 카드(translateY +160 → 0), 480ms, 80ms stagger. 적용/비적용 범위 명시.

- **InteractiveSplash** — 검은 overlay 덧칠 제거, 중복된 'AURA' 워드마크 제거(배경 이미지에 이미 'Aura' 들어있음), 안내 문구 "어디든 터치하세요 / Tap to enter" 한 줄 + textSecondary 톤. 터치 시 120ms fade-out.

- **SignIn 진입 애니메이션** — HeroGradient(상단)와 formCard(하단)를 `Animated.View`로 감싸 mount 시 각자 방향에서 슬라이드 인. Reanimated 추가 없이 RN 기본 `Animated` API.

### 2차 패스 — "전체적으로 밋밋함" 피드백 반영

- **ScreenAtmosphere 색감 강화** (가장 큰 임팩트)

  - 두 layer 구조: 상단 aurora glow (alpha 0.22→0.14→0.06→0, 영역 360→420px) + 우하단 calm tint(신규).
  - HeroGradient 없는 화면(ask, settings)도 atmosphere만으로 충분히 풍성.

- **PrimaryButton 입체화** (sign-in)

  - flat Pressable → 그림자/glow + press feedback. 그림자 색이 background에 동기화 (aurora 톤은 보라 glow, kakao는 옐로 glow, 그 외는 잉크).
  - press 시 scale 0.97 + 그림자 약화 → 햅틱적 반응.

- **카드 elevation 강화** (`shell.ts`) — formCard / sectionCard 그림자 강도 ↑ (opacity 0.16→0.22, radius 22→26). 라이트 모드 그림자 색을 더 진한 보라 톤으로.

- **5탭 아이콘 line SVG로 교체** (`tab-icons.tsx` 신설)
  - 기존 유니코드 글리프(`✉︎ ◷ ☰ ◉ ⚙︎`) — 폰트별 렌더링 다르고 짜침.
  - 신규: `react-native-svg`로 직접 그린 5개 line 아이콘. 24×24, stroke 1.75, Phosphor 톤. Mail / Todo / News / Ask(채팅 + sparkle, 브랜드 톤) / Settings.
