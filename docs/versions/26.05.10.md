# 2026-05-10 패치 노트

Phase G.2 + Phase H 통합 업데이트. 사용자 행동 데이터를 자동으로 활용해 brief의 톤·시간·내용을 본인에게 맞춰주고, mail 자체에서 캘린더/구독 정리까지 1-tap으로 해결.

## Features

### G.2 — Android Health Connect 통합

- Backend `daily_health` table (migration 0011 daily_brief_open_events 와 함께 0010): user_id+date PK, 30일 보관.
- POST `/api/v1/me/health/daily` — frontend가 매일 morning brief 직전 native(Health Connect)에서 어제 sleep / steps / HR을 pull → upsert.
- Android native `AuraHealthModule.kt` — `androidx.health.connect:connect-client` 1.1. minSdk **24 → 26** 상향 (Android 7.x <1% 점유).
- 권한 부여 deeplink는 `android.health.connect.action.HEALTH_HOME_SETTINGS`. 사용자가 Settings → 권한에서 "Health Connect 연결" 누르면 native 화면 열림 → 부여 후 silent sync.
- iOS HealthKit은 Apple Developer 활성 후 진행 (G.2.3, 보류).

### G.2.B — Brief에 wellnessTip 주입

- `briefings/wellness.ts` — 어제 sleep/steps 기반 한 줄 톤 조절. **LLM 호출 없음** (deterministic).
  - 5h 미만 → "어제 4.2시간으로 부족했어요. 오늘은 무리하지 말고 가볍게 시작해보세요."
  - 7-9h → "솔리드. 오늘 컨디션 좋을 거예요."
  - 걸음 3000보 미만 → "잠깐 산책 어떠세요?"
- DailyBriefModal에 `♡ 오늘의 컨디션` 카드 추가. 데이터 없으면 카드 자체 숨김.
- 구버전 snapshot은 default `{yesterday: null, wellnessTip: null}`로 자동 보강.

### H.1 — Brief 열람 시각 학습 + 추천 시간

- 새 table `aura.daily_brief_open_events` (migration 0011) — 사용자가 modal을 열 때마다 timestamp 저장. 30일 보관.
- POST `/briefings/opened` (quota 차감 X), GET `/briefings/suggested-time` — 7일 평균을 사용자 timezone 기준으로 환산해 HH:MM:SS 반환.
- Settings → 알림에 **"추천 시간 (지난 7일 평균): 08:42 — 적용"** row. 자동 적용은 안 함 (사용자 confirm).

### Daily brief 하루 1회 자동 표시

- AsyncStorage `aura.app.dailyBriefLastShownDate`. cold start 시 오늘 local 날짜와 비교 → 같으면 **prepare 자체를 skip** (modal 안 뜨고 backend 호출도 없음). 사용자 명시 reload는 항상 표시.
- Push tap (`pendingDailyBriefOpen`) 분기에서도 표시 직후 `lastShownDate=today` mark — 이후 cold start 시 중복 차단.
- 효과: 에뮬레이터/Cmd+R로 reload 자주 해도 quota 누적 0.

### H.2 — 자동 unsubscribe 제안

- 최근 30일 inbox에서 `List-Unsubscribe` header가 있는 발신자를 group → "구독 해제 후보 N개". LLM 미사용 — Gmail metadata만, quota 차감 X.
- RFC 8058 `List-Unsubscribe-Post: List-Unsubscribe=One-Click` 명시된 발신자는 backend가 `POST` 자동 발송 → 1-tap 즉시 해제.
- 그 외(보통 mailto: 또는 비-1click https)는 frontend가 `Linking.openURL`로 외부 브라우저/메일 앱에 위임. Settings → 메뉴 → "구독 정리" 화면.

### H.3 — Mail → 일정 자동 추출

- 메시지마다 작은 `📅 일정` 버튼 추가. 누르면 backend가 본문(text/plain 우선, html stripped fallback, 6,000자 cap) + 사용자 timezone을 Anthropic에 전달 → JSON `{title, startsAt, endsAt, location, allDay, details, hasEnoughInfo}` 추출.
- 결과를 `CalendarExtractModal`로 미리보기 → "Google Calendar로 추가" 버튼이 `https://calendar.google.com/calendar/render?action=TEMPLATE&...` URL로 외부 처리. **OAuth 캘린더 write scope 필요 없음** — Aura 권한 표면 0 증가.
- 사용자가 trigger했을 때만 LLM 호출. quota는 `email_summary` feature로 차감 + token 기록.

### Backend

- 새 모듈 `back/src/modules/health/` (service + routes + index). Mount path `/api/v1/me/health` (server health check `/health`와 분리).

- gmail 모듈 추가 함수: `fetchGmailMessageBody`, `fetchUnsubscribeCandidates`, `postOneClickUnsubscribe`, `extractCalendarEventFromMessage`.

### Frontend

- 새 features 모듈: `features/health/{api,sync}.ts`, `features/calendar/google-template.ts`.
- 새 컴포넌트: `CalendarExtractModal`.
- 새 Settings section: `unsubscribe-section.tsx` + 메뉴 진입 row.
- `SettingsSectionKey`에 `unsubscribe` 추가.

### Android 빌드 변경

- `minSdkVersion 24 → 26` (`front/android/build.gradle`). Android 7.x(<1%) 단말 차단. RN 0.84 권장 minSdk와 일치.
- 새 dependency `androidx.health.connect:connect-client:1.1.0-rc03`.
- 새 manifest 권한 3개: `android.permission.health.READ_SLEEP / READ_STEPS / READ_HEART_RATE`.
- `<queries>`에 `com.google.android.apps.healthdata` (Android 11+ package visibility).
- `MainApplication`에 `AuraHealthPackage` 등록.
