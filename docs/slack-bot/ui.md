# 웹 UI 플로우

> `web/` Next.js 프로젝트 내 `/slack` 라우트.  
> 기존 AURA 웹과 동일한 디자인 토큰 재활용.

---

## 페이지 구조

```
/slack               ← 랜딩 (설치 소개)
/slack/setup         ← 3-step 설정 마법사
/slack/settings      ← 설치 후 설정 관리
```

로그인 불필요 — GitHub OAuth 자체가 인증 역할.  
AURA 앱 계정과 연동 없음 (독립 서비스).

## 2. 설정 마법사 `/slack/setup`

3-step으로 진행. URL에 step 파라미터 없이 클라이언트 상태로 관리.

```

├─────────────────────────────────────────────────────┤
│                                                      │
│  GitHub Organization에 접근 권한이 필요합니다.        │

│  ✓ Repository 커밋 읽기 (쓰기 권한 없음)             │
```

## 컴포넌트 설계

기존 `web/` 디자인 토큰 (`--aurora`, `--surface`, `--line` 등) 그대로 사용.

```typescript
// 공유 컴포넌트 목록
web/src/components/
  slack-bot/
    SetupWizard.tsx         ← 3-step 마법사 컨테이너
    RepoSelector.tsx        ← 체크박스 + 검색 필터
    TimezonePicker.tsx      ← 시간 + timezone 선택
    DigestLogTable.tsx      ← 실행 기록 테이블
    SlackAddButton.tsx      ← "Add to Slack" 공식 버튼
```

## 인증 세션 관리

GitHub OAuth 완료 후 token을 클라이언트에 노출하지 않음.

```typescript
// Next.js cookie로 세션 관리 (httpOnly)
// /api/github/callback에서 설정
response.cookies.set("bot_session", sessionId, {
  httpOnly: true,
  secure: true,
  sameSite: "lax",
  maxAge: 60 * 60 * 24  // 24시간
});
```

실제 GitHub token은 DB에만 저장 (AES-256-GCM 암호화).
