# AURA Business Mode

> 개인이 쓰지만, 팀과 공유하기 쉬운 업무 도구.

---

## 방향

하나의 앱, 두 가지 모드.

- **Personal** — 현재 AURA. 개인 일정·메일·건강·출퇴근.
- **Business** — 회사에서 쓰는 AURA. 회의·보고·팀 공유.

온보딩에서 선택. 백엔드 `users.account_type: "personal" | "business"`.  
팀 멤버 관리, 권한 시스템 없음 — 개인이 생성하고 공유 링크로 배포.

---

## 핵심 문제

직장인의 하루에서 가장 시간을 쓰는 것:

| 활동 | 고통 |
|------|------|
| 이메일 | 이미 AURA가 커버 ✅ |
| 회의 | 회의는 많은데 아무것도 남지 않음 |
| 정보 검색 | "그거 어디서 정했더라" |
| 보고 | 주간 보고 쓰는 데 1시간 |

**회의가 비어있다.** 그리고 모든 직장인에게 공통이다.

---

## 회의 자동화 — 핵심 기능

### 회의 전: 브리핑 알림

캘린더에 회의가 있으면 30분 전 push.

```
📋 OO 미팅 30분 후
ㄴ 참석자: 김OO, 이OO
ㄴ 관련 메일: "지난주 피드백 건" (3일 전)
ㄴ 준비: 자료 공유 여부 확인
```

이미 있는 것 재활용: Calendar 연동 + Gmail 요약 + departure alarm 패턴.

---

### 회의 중: 노트 에디터 + 실시간 STT

화면을 두 패널로 나눔.

```
┌──────────────────────┬──────────────────────────────┐
│  📝 내 노트          │  💬 실시간 자막               │
│  (에디터)            │  (STT 출력)                   │
└──────────────────────┴──────────────────────────────┘
```

**에디터 입력 형식 — 사용자가 선택:**

| 형식 | 특징 | 적합한 사람 |
|------|------|------------|
| **Markdown** | 경량, 빠른 입력, 코드 블록 지원 | 개발자·기술직 |
| **DOCX** | 서식 있는 편집, Word 호환 | 기획·영업·관리직 |

설정에서 기본값 지정. 노트 생성 시 변경 가능.  
저장·내보내기 시 선택한 형식으로 출력.

**STT 파이프라인:**

```
브라우저 getDisplayMedia (화상회의 시스템 오디오)
또는 마이크 (현장 회의)
        ↓
  오디오 스트림 → Whisper API ($0.006/분)
        ↓
  실시간 텍스트 → 오른쪽 패널 표시
```

한국어: Whisper로 시작, 정확도 문제 시 CLOVA Speech 전환.

---

### 회의 후: AI 정리 + 공유

[종료] 버튼 누르면:

```
내 노트 + 자막 원문
        ↓
  Anthropic — 선택한 템플릿 구조로 추출
        ↓
  편집 가능한 회의록 생성
        ↓
  [공유] → 링크 / Slack / 이메일
  [내보내기] → .md 또는 .docx
```

## 회의록 템플릿

회의 시작 시 선택. AURA가 5가지 제공, 빈 양식도 선택 가능.

### 1. 일반 회의 *(기본값)*
```
# [회의명]  [날짜]  [참석자]

## 목적

## 주요 논의

## 결정 사항

## 액션 아이템
| 담당자 | 내용 | 마감 |
|--------|------|------|

## 다음 회의
```

---

### 2. 주간 스탠드업
```
# 스탠드업  [날짜]

## [이름]
- 어제:
- 오늘:
- 블로커:

## 공지
```

---

### 3. 1:1 미팅
```
# 1:1  [이름]  [날짜]

## 근황

## 진행 중인 업무

## 피드백

## 다음까지 할 것
```

---

### 4. 고객 미팅
```
# [고객사]  [날짜]  [담당자]

## 고객 요구사항

## 논의된 내용

## 다음 단계
| 담당 | 내용 | 기한 |
|------|------|------|

## 후속 발송 내용
```

---

### 5. 프로젝트 회의
```
# [프로젝트]  [날짜]

## 현황 요약

## 이슈 / 리스크

## 결정 사항

## 액션 아이템
| 담당자 | 내용 | 마감 |
|--------|------|------|
```

## 팀 공유 모델

팀 DB, 멤버 관리 없음. 공유 토큰만.

```
meeting_notes
  id
  user_id
  title
  body             ← AI 정리 결과 (Markdown)
  raw_transcript
  format           ← "markdown" | "docx"
  template_id
  share_token      ← 읽기 전용 URL (로그인 불필요)
  created_at
```

공유 방식:
- **링크 복사** → 누구나 읽기 가능
- **Slack 전송** → 채널 + 요약 텍스트 자동 포맷
- **이메일** → 참석자에게 일괄 발송
- **내보내기** → `.md` 또는 `.docx` 다운로드

## 웹앱 디자인

**기본 원칙:**
- 라이트 모드 기본 (다크 토글 지원)
- 배경 `#FFFFFF`, 사이드바 `#F8F7FC`, 강조 `#6B5BFF` — AURA 토큰 재활용
- 스택: Next.js (백엔드 API 재사용)

**배포**: Vercel (Next.js → Vercel 자동 연동)

**레이아웃:**

```
┌──────────┬────────────────────────────────────────────┐
│ 사이드바  │  메인 콘텐츠                               │
│          │                                            │
│  대시보드 │  ← 회의 중: 노트 + 자막 2패널             │
│  회의록   │  ← 회의 후: 정리된 회의록 뷰              │
│  설정     │  ← 대시보드: 오늘 회의 + 최근 회의록      │
│          │                                            │
└──────────┴────────────────────────────────────────────┘
```

**회의 중 화면 — 최우선 최적화 대상:**
- 두 패널이 50:50
- 상단 바: 녹음 중 표시 + 타이머 + [종료 + 요약] 버튼만
- 사이드바 숨김 옵션 (집중 모드)

## 빌드 순서

### Step 1 — 회의 브리핑 push *(기존 코드 재활용, 빠름)*
캘린더 이벤트 30분 전 → 참석자 + 관련 메일 요약 push.

### Step 2 — 웹앱 + 에디터 + 템플릿
Next.js 프로젝트 + Google OAuth + 마크다운/DOCX 에디터 + 템플릿 선택.

### Step 3 — STT 연동
`getDisplayMedia` + Whisper 스트리밍 → 실시간 자막 패널.

### Step 4 — AI 회의록 정리 + 공유
Anthropic 호출 → 템플릿 구조로 추출 → 공유 링크 + Slack webhook + 내보내기.

### Step 5 — Slack RAG 봇 *(선택)*
`/aura [질문]` → 팀 Slack 히스토리 검색 → AI 답변.
